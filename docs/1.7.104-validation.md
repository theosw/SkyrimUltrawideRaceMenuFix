# Skyrim 1.7.104 validation

This document records the evidence for the Skyrim 1.7.104 compatibility
change. It is a targeted build, static relocation, and runtime smoke test; it
is not a claim that every supported runtime or mod combination was exercised.

## Inputs

- Plugin source baseline: `0f0079d15c0aecaaf82f292d8c7266aa161d3e9c`
- CommonLibSSE-NG: v11.0.0,
  `94faaed0c60eddd8347767f2d4d29a97c93bde8c`
- Build: Visual Studio 2022, MSVC 19.43.34808, x64 AE Release
- Runtime: SkyrimSE.exe 1.7.104.0 with SKSE64 2.3.1
- Address Library: `versionlib-1-7-104-0.bin`, format 5
- Display used for the smoke test: 5120x1440 (32:9)

The previously distributed 0.1.1 DLL exited during startup with
`Unsupported address library format: 5`. CommonLibSSE-NG v11.0.0 has an
explicit format-5 reader, and the plugin declarations in this tree use that
release's API.

## Build checks

- A clean AE Release configure and build completed successfully.
- The output is an x64 DLL with file and product version 0.1.1.0.
- `SKSEPlugin_Load`, `SKSEPlugin_Query`, and `SKSEPlugin_Version` are exported.
- CTest discovered no tests in the upstream project.
- Release DLL SHA-256:
  `F9F56CF5C838FAAEC33B142CF05BA47C94F26A911F2A113208DC4FEC3E1667BD`

## Static hook check

The installed format-5 database identified itself as Skyrim 1.7.104.0 and
contained 565,759 dense offsets. CommonLibSSE-NG's AE relocation ID 215883 for
`VTABLE_RaceSexCamera` resolved to RVA `0x197ED90`. Vtable slot 2 then resolved
to RVA `0x9678C0` inside the executable `.text` section, consistent with the
`RaceSexCamera::Update` virtual that this plugin replaces.

## Runtime smoke test

The rebuilt DLL was installed as a separate Mod Organizer 2 mod so the
original package remained available. On a fresh 1.7.104 launch, SKSE reported:

```text
plugin UltrawideChargenCameraFix.dll (00000001 UltrawideChargenCameraFix 00010010) loaded correctly
```

The plugin log reported:

```text
UltrawideChargenCameraFix v0-1-1-0
RaceSexCamera::Update hooked
UltrawideChargenCameraFix loaded
```

A manual RaceMenu test at 5120x1440 confirmed that the corrected chargen
camera framing works. No automated camera regression tests are supplied.
